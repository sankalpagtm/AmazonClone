# 🛒 Amazon Clone (HTML & CSS)

This is a static **Amazon clone website** built using only **HTML** and **CSS**. It replicates the layout and design of Amazon's homepage for learning and practice purposes.

---

## 🚀 Features

- 🖼️ Static layout of Amazon homepage
- 🔍 Search bar UI
- 🛍️ Product listings with images, prices, and descriptions
- 📦 Header with logo and navigation links
- ✨ Hover effects and clean layout

> ⚠️ This project is not responsive — best viewed on desktop.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox and basic layout styling)
